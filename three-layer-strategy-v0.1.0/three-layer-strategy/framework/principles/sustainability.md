# Sustainable AI use

Efficiency is part of quality.

- Load the smallest relevant context instead of the entire repository.
- Use deterministic tools for search, formatting, calculation and validation when they suffice.
- Batch independent checks; avoid repeated generation of nearly identical artifacts.
- Store accepted decisions so they are not rediscovered in later conversations.
- Use smaller or local models when capability and policy allow it.
- Stop agent loops when evidence is not improving.
- Include human review cost in automation decisions: unreadable machine output is waste.

The framework does not assign a universal carbon value to a token. It requires teams to make resource consumption visible and proportionate to the expected outcome.
