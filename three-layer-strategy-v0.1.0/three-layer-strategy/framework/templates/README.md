# Change bundle templates

Every proposed change uses the same six-file bundle:

1. `intent.md` — why and for whom;
2. `assessment.md` — which execution mode and controls;
3. `spec.md` — observable behavior;
4. `plan.md` — implementation approach;
5. `tasks.md` — executable increments;
6. `verification.md` — evidence and final status.

Copy the templates without removing headings. Use `Not applicable — <reason>` when a section genuinely does not apply.
