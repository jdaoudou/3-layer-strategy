# Project agent instructions

This project uses Three-Layer Strategy.

## Bootstrap

1. Read `.aidd/principles.md` and `.aidd/config.yaml`.
2. For a change, read its complete folder under `.aidd/changes/`.
3. Treat `.aidd/specs/` as current product truth and the change folder as a proposed delta.
4. Follow the execution mode selected for the current workflow step.
5. Never implement unresolved behavior that would alter acceptance criteria.
6. Run project checks and record evidence before declaring completion.
