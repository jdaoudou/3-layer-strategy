# Three-Layer Strategy — Codex adapter

Read `.aidd/principles.md` and `.aidd/config.yaml` before change work.

For change work:

1. Resolve the active folder under `.aidd/changes/`.
2. Do not build before intent, assessment and spec contain enough information for the selected execution mode.
3. Load only the relevant Three-Layer skill.
4. Respect file/tool boundaries in `assessment.md`.
5. Update tasks and verification evidence as work progresses.
6. Do not declare completion until acceptance criteria are evidenced.

Canonical framework rules override this adapter.

Add the project's real install, test, lint, build and run commands below this line.
